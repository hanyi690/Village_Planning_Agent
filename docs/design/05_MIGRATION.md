## 1. Status and evidence rules

状态只使用：

- `CURRENT`：当前工作树有明确 owner、生产调用路径和可重复正向验证；只对该行限定的 capability 成立。
- `PARTIAL`：已有真实实现或测试锚点，但 shape、调用覆盖、自动 gate、fresh verification 或 release evidence 仍不完整。
- `GAP`：目标 capability 尚无当前可复核实现闭环。
- `RETIRE`：旧路径只允许兼容读取、审计或历史说明，不能恢复为 authority。
- `BLOCKED`：存在已确认阻塞，当前工作树无法继续验证。

`CURRENT` 不等于全系统完成；本表不使用 `COMPLETE`。代码路径只能证明实现存在，测试文件只能证明有可运行断言；只有本表明确记录的实际命令结果才是本轮 runtime-verified evidence。历史 session/run ID 只在 `CURRENT_RUNTIME.md` 保存。
