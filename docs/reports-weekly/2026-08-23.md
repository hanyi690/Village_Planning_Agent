## 一、结论先行

本周已经把“一个真实源地块内的局部规划”跑通到可审计交付：`ScenarioSet → ApprovedExecutionInput → atomic EXECUTE → VALIDATE(passed) → RECONCILE → DELIVER` 全链路成立，前端能加载同一 session 的非空规划图层。最新代码下的 session `4957576d-ed98-4847-a026-361f6c739dbe` 已在同一次运行中达到 `delivery_status=complete`、`statutory_complete=true`；这个结果仍是 **PARTIAL**，不是全村法定规划完成：它只证明一个明确窄切片目标，且道路、覆盖、网络、拓扑等专用规划后端尚未在全村输入上形成正式方案。

本周针对大地块与邻接语义做了边界收紧：

- `fully_unavailable` 不进入 SELECT/EXECUTE；`partially_available` 只允许裁切后的 footprint，并保留 excluded 区域和 source BSM；`fully_available + coverage_ratio < 1` 表示“只分配了子几何”，不表示整块地被约束排除；`unknown` 继续 fail-closed。
- 大地块执行只生成获批 footprint + 同源 preserve/remainder，不恢复成完整 BSM；候选的面积预算在批准后冻结，缺失面积时才从 WKT 与 metric CRS 推导。
- 相邻 BSM 只作为上下文和证据传递，不会自动合并或改写。若规划要求执行时协调邻地，必须同时有邻接 BSM、邻接证据和 typed relation ref；缺任何一项就延期。
- 显式窄切片 claim 会在 SELECT 的 suitability 计算前裁剪输入候选，但完整 GROUND artifact 仍保留全量召回结果；普通任务不会获得这个范围缩减。

## 五、距离合理规划产出的剩余问题

“合理规划产出”必须按层级判断，不能用这次一个窄切片的非空地图替代全村规划：

| 层级 | 当前状态 | 还缺什么 |
|---|---|---|
| 单地块局部 site footprint | **已有最新真实闭环证据** | 已在 session `4957576d-ed98-4847-a026-361f6c739dbe` 验证 footprint/remainder、面积分割、邻接上下文和前端规划图层；仍需补 fully_unavailable/partially_available 的负例与多源面积一致性 |
| 多地块 site-area / 多项目 | **PARTIAL（后端契约已接入）** | `ParcelResourcePool` 已实现同源容量/重叠约束并注册 `parcel_assignment_bounded`；仍缺真实多地块候选生成、跨目标 approved ScenarioSet、混合 worker 同一次原子验收和 Playwright 图层核验 |
| 多设施覆盖 | GAP | DemandSnapshot、容量/距离矩阵和正式 coverage backend |
| 道路连通/走廊 | GAP | typed endpoints、NetworkGraphSnapshot、route candidate 和 network backend |
| 分区拓扑/邻接布局 | GAP | adjacency/partition/co-locate typed factors 和 topology solver |
| 全村法定规划 | **未完成** | L3 目标准入、候选完整性和以上专用后端在真实输入上稳定产出 |

按当前代码状态给出的是工程量区间而非承诺：带 marker 的单地块 fresh 复跑（含人工 gate 与 Playwright 核验）约 30–60 分钟墙钟时间；多地块 site-area 后端首个可审计切片（已有容量/重叠契约）还需要约 1–3 个工程日，真实 mixed-worker + Playwright 验收约再 1–2 个工程日；coverage/network/topology 和混合子图、失败路径、重放至少是后续 1–2 个迭代周期；全村法定规划不能在 L3 仍大量产生无对象、无 typed parameters 的目标时给出可靠日期。
