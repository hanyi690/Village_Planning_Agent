# GIS 输出架构 — 广东省村庄规划标准

> 版本: 1.0 | 日期: 2026-07-15 | 参照: 广东省村庄规划编制基本技术指南（试行） + 金田村实测数据

## 设计原则

1. **输出驱动**：以广东省汇交标准定义输出层，反向推导生成层
2. **输入即真实**：以 `data/gis/jintian/` 实测数据为唯一输入真相
3. **分层解耦**：输入 → 内部生成抽象 → 标准输出，每层独立可替换
4. **可扩展**：新增省份标准 = 新增一个 output profile，不改生成核心

## 二、输出（14 层，广东标准）

### 2.1 输出目录结构

```
output/{village_name}/
├── 01_boundary.geojson                   ← current/ 直出
├── 02_admin_boundary_line.geojson        ← current/ 直出
├── 03_current_landuse.geojson            ← current/ 直出（基准）
├── 04_current_road.geojson               ← current/ 直出
├── 05_current_annotation.geojson         ← current/ 直出
├── 06_planned_landuse.geojson            ★ 地块重分类层（16字段）
├── 07_farmland_protection.geojson        ★ 外部权威数据（自然资源部"三区三线"）
├── 08_ecological_protection.geojson      ★ 外部权威数据（自然资源部"三区三线"）
├── 09_historical_protection.geojson      ★ 外部数据（地方住建/文旅部门提供）
├── 10_space_control_zone.geojson         ★ 建设用地空间管制区（4类，基于保护红线+建设边界计算）
├── 11_land_use_zone.geojson              ★ 土地用途分区（V/N/E 三大类）
├── 12_geological_hazard_points.geojson   ★ 外部数据（地灾调查成果导入）
├── 13_planned_road.geojson               ★ 规划道路
├── 14_planned_annotation.geojson         ★ 规划注记
├── tables/
│   └── land_balance.json                 用地平衡表
└── layout.json                           布局配置
```

### 2.2 各输出层详述

#### 06 期末地类图斑（★ 核心生成层）

对标 `planned/landuse.geojson` 完整 16 字段：

| 字段 | 类型 | 生成方式 |
|------|------|---------|
| BSM | str:18 | 自动编码 |
| YSDM | str:10 | 固定 2003070100 |
| TBH | str:10 | 自动编码 |
| XZQHDM | str:12 | 固定 441426108004 |
| XZQHMC | str:50 | 金田村委会 |
| DLBM | str:4 | 从 current/landuse 继承 |
| DLMJ | float64 | 几何计算 |
| **QMDLBM** | str:4 | ★ 生成：期末 DLBM（重分类后编码） |
| LYYSDM | str:10 | — |
| **GHFLBM** | str:4 | ★ 生成：规划分类编码 |
| QMGHFLBM | str:4 | = GHFLBM |
| **GHYTBM** | str:4 | ★ 生成：规划用途编码 |
| **GHYTMC** | str:20 | ★ 生成：从 GHYTBM 查表 |
| MS | str:10 | — |
| Shape_Length | float64 | 几何计算 |
| Shape_Area | float64 | 几何计算 |

实测数据中 GHYTMC 值示例：耕地、商品林、宅基地、坑塘水面、草地等。

#### 10 建设用地空间管制区（★ 广东数据库汇交必选）

| 类型 | 代码 | 生成规则 |
|------|------|---------|
| 允许建设区 | 510 | 村庄建设边界内部 |
| 限制建设区 | 520 | 除以下三类以外的区域 |
| 有条件建设区 | 530 | ≤ 现状建设用地 × 20%，不占基本农田 + 生态红线 |
| 禁止建设区 | 540 | 永久基本农田 + 生态保护红线（不可调整） |

质量规则：允许建设区和有条件建设区内不能有基本农田；有条件建设区内不能规划建设用地。

#### 11 土地用途分区（★ V/N/E 三大类体系）

采用住建部《村庄规划用地分类指南》，广东附录E直接引用。**3大类、10中类、15小类**：

```
V  村庄建设用地
  V1  村民住宅用地
    V11  住宅用地
    V12  混合式住宅用地
  V2  村庄公共服务用地
    V21  村庄公共服务设施用地  （村委会、学校、卫生站、文化站等）
    V22  村庄公共场地            （广场、小绿地）
  V3  村庄产业用地
    V31  村庄商业服务业设施用地  （小超市、集贸市场、旅游接待）
    V32  村庄生产仓储用地        （手工业、食品加工、仓库堆场）
  V4  村庄基础设施用地
    V41  村庄道路用地
    V42  村庄交通设施用地        （停车场、公交站点）
    V43  村庄公用设施用地        （给排水、供电、公厕、垃圾站、消防）
  V9  村庄其他建设用地           （未利用/待研究的集体建设用地）

N  非村庄建设用地
  N1  对外交通设施用地           （过境公路、铁路）
  N2  国有建设用地               （公用设施、特殊用地、采矿用地等）

E  非建设用地
  E1  水域
    E11  自然水域                （河流、湖泊、滩涂）
    E12  水库
    E13  坑塘沟渠
  E2  农林用地
    E21  设施农用地              （畜禽舍、大棚、晾晒场）
    E22  农用道路                （机耕道、林道）
    E23  其他农林用地            （耕地、园地、林地、牧草地、田坎）
  E9  其他非建设用地             （空闲地、盐碱地、沼泽地、裸地）
```

**与当前 DLBM 48 类的关系**：DLBM 是"三调"工作分类（地类现状），V/N/E 是村庄规划用途分类（规划用途）。期末地类图斑通过 GHFLBM/GHYTBM 双编码桥接两者。V/N/E 分类通过 DLBM → GHFLBM/GHYTBM → V/N/E 查表完成。

## 三、内部生成层（5 层中间抽象）

```
输入                          5 个内部生成层                      输出
──────────────────────────────────────────────────────────────────────
current/ GIS 数据 ───────────────────────────────────→ 01-05 (直出)

规划文本 ──→ ① ParcelReclass (地块重分类)
                 DLBM → QMDLBM/GHFLBM/GHYTBM/GHYTMC
                 ├──────────────────────────────────→ 06 期末地类图斑
                 │
                 ├──→ ② SpaceControl (空间管制分层)
                 │       允许/限制/有条件/禁止 4 类
                 ├──────────────────────────────────→ 10 管制区
                 │
                 ├──→ ③ UseZone (用途分区)
                 │       DLBM → V/N/E 分类
                 ├──────────────────────────────────→ 11 用途分区
                 │
                 ├──→ ④ FacilityPlan (设施布点)
                 │       8 类村级公共服务设施
                 ├──────────────────────────────────→ 14 规划注记
                 │
                 └──→ ⑤ RoadPlan (道路规划)
                         路网调整 + 新增
                 └──────────────────────────────────→ 13 规划道路

planned/ 保护红线 ──────────────────────────────────→ (仅测试参考，生产环境用外部权威数据)

外部权威数据（自然资源部"三区三线"） ────────────→ 07-09, 12 (校验后纳入)
```

### 各内部层契约

**① ParcelReclass（地块重分类）**

| 项目 | 说明 |
|------|------|
| 输入 | current/landuse (660 features, DLBM 编码) + 规划文本解析结果 (zones: area_ratio, land_use) + GIS 面积约束 |
| 处理 | 每地块：DLBM → 目标用途 → QMDLBM/GHFLBM/GHYTBM/GHYTMC（保留不可调整的保护地块） |
| 输出 | 重分类后地块集合，每 feature 含完整 16 字段 |
| 约束 | 建设用地总量 ≤ GIS 实测上限，耕地保有量 ≥ 下限，基本农田/生态红线地块不可改 |

**② SpaceControl（空间管制分层）**

| 项目 | 说明 |
|------|------|
| 输入 | ① 输出 + farmland_protection + ecological_protection + 村庄建设边界 |
| 输出 | 4 类管制区多边形（全域覆盖不重叠） |
| 规则 | 禁止建设区 = 基本农田 ∪ 生态红线；允许建设区 = 村庄建设边界；有条件建设区 ≤ 现状建设用地×20%；其余 = 限制建设区 |

**③ UseZone（用途分区）**

| 项目 | 说明 |
|------|------|
| 输入 | ① 输出 + V/N/E 分类映射表 |
| 输出 | 村域全覆盖用途分区多边形，按 V/N/E 中类编码 |
| 映射 | DLBM/GHYTBM → V/N/E 查表转换 |

**④ FacilityPlan（设施布点）**

| 项目 | 说明 |
|------|------|
| 输入 | 规划文本解析结果 (facilities: type, status, target_zone) + ① 输出（建设用地位置） + 村庄建设边界 |
| 输出 | 8 类公共服务设施点（村委会/学校/卫生站/文化站/市场/养老服务/产业服务中心/停车场） |

**⑤ RoadPlan（道路规划）**

| 项目 | 说明 |
|------|------|
| 输入 | current/road + ① 输出（新增建设用地连通需求） |
| 输出 | 规划道路网络 |

## 五、可扩展性：省份 Profile

```python
class OutputProfile:
    """不同省份 = 不同 OutputProfile，生成核心不变"""
    province: str                        # "guangdong" | "shanxi" | "henan" | ...
    
    # 期末地类字段标准
    landuse_fields: List[FieldSpec]      # 字段名 + 类型 + 默认值
    
    # 用途分区分类表
    use_zone_categories: Dict            # 分类代码 → {name, parent, children}
    
    # 管制区划分规则
    control_zone_rules: Dict             # {zone_type: rule}
    
    # 必选输出层
    required_layers: List[str]
    
    # 坐标系
    crs: str                            # EPSG:4527 (CGCS2000 3° GK39)
    
    # 数据库格式
    db_format: str                      # "mdb" | "gdb" | "geojson"
```

## 七、验证方式

1. **输出完整性**：14 个输出层 vs `planned/` 参考数据，逐层覆盖
2. **字段完整性**：06 期末地类 16 字段 vs `planned/landuse.geojson` 字段逐一校验
3. **标准合规**：对照广东数据库汇交必选图层清单逐项检查
4. **面积约束**：建设用地 ≤ GIS 实测上限，耕地 ≥ 下限，生态红线面积 ≥ 下限
