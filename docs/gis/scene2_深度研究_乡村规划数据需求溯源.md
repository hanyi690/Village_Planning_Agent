## 2. 底图底数数据(空间数据之"底")

### 2.1 权威底图来源(优先级有明确规定)

1. **第三次全国国土调查("三调")或最新年度国土变更调查成果**——法定底数:
   - "应采用第三次全国国土调查数据成果或最新土地变更调查数据成果……作为工作底图"【广东指南·二-1】;
   - "以第三次国土调查的行政村界线为规划范围……统一底图底数"【09号文·二条】;
   - 村庄建设边界规模上限="**2020年度国土变更调查村庄用地(203)规模**"【2024年1号文·一条】;
   - "以2020年国土变更调查数据为基础,优先划定耕地和永久基本农田"【梅州市规划·13条】。
2. **数字线划地图(DLG)和不比例尺低于1:2000的地形图或国土数字正射影像图(DOM)**【广东指南·二-1】;
3. **补充数据:农村地籍调查数据、地理国情普查及监测数据**【广东指南·二-1】;
4. **宅基地确权登记发证成果**(结合开展宅基地调查)【村土导则·附录三】;
5. **不动产登记成果**【全域整治指南·四(三)1】;
6. **地形图获取路径**:"乡村地区有时无法直接获取地形图,需要向县级以上的土地管理部门索要,或提前通知相关部门测绘"【李京生·第9章】;"若无现成图件,应及时进行测绘"【村庄整治技术规范·1.0.5】。

### 2.2 "三调"矢量数据内部结构(智能体建模直接可用)

【李巍手册·2.1.1/表2-1】三调成果"矢量数据按照空间要素采用分层的方法组织管理,分为九个分层要素";村庄规划最核心的是**地类图斑(DLTB)**与**村级调查区(CJDCQ)**两图层。地类图斑"至少包含30个字段",关键字段:

| ZLDWDM / ZLDWMC | 坐落单位代码/名称("村域范围一般以坐落单位代码和名称为主"——即按此筛选村域图斑) |
| TBMJ | 图斑面积("为坐标计算的椭球面积") |
| GDLX | 耕地类型(坡地PD/梯田TT) |
| GDPDJB | 耕地坡度级别五级:≤2°、2°~6°、6°~15°、15°~25°、>25° |
| XZDWKD | 线状地物宽度 |
| ZZSXDM | 种植属性八种:LS粮食/FLS非粮/LYFL轮作/WG未耕种/XG休耕/LLJZ林粮间作/JKHF即可恢复/GCHF工程恢复 |
| GDDB | 耕地等别(按GB/T 28407) |
| CZCSXM | 城镇村属性码:城市201、建制镇202、**村庄203**、盐田采矿204、特殊用地205 |

技术依据:《第三次全国国土调查技术规程》TD/T 1055—2019、《国土调查数据库标准(试行修订稿)》【李巍手册·2.1.1】。

### 2.3 补充调查的触发条件与做法

- "适用于缺少大比例尺工作底图的地区":①在年度变更调查基础上补充调查绘制1:2000现状图;②结合宅基地确权登记发证成果开展宅基地调查;③土地整理复垦开发潜力调查;④土地生态环境调查;成果"应由地籍部门审核同意"并"说明成果与土地利用变更调查成果的差异情况"【村土导则·附录三】。
- 大比例尺调查发现的永久基本农田图斑内非农建设用地或零星农用地,"在村规划中应当优先整理、复垦为耕地"【村土导则·三(五)1】。

## 10. 对 Village_Planning_Agent 的落地建议

结合项目KG架构定案(所有空间图层均为KG实体、约束面入L1、EntityCard统一序列化、~10个查询模式),本研究给出直接映射:

1. **KG实体类型注册表(建议首批)**:parcel地类图斑(DLTB/QMDLTB)、zone控制面(STBHHX/YJJBNT/YJJBNTCBQ/ZJDJSFWX/YJJSQ有条件建设区/LSWHBHFW/QTKZX/JSYDGZQ管制区)、boundary村庄建设边界、building建筑(含金田村式四类质量属性)、facility设施(公服/市政,台账式字段)、road道路(等级/宽度/硬化)、water水系(河道+管护范围)、heritage历史文化资源、hazard灾害隐患点(类型/位置)、project近期建设项目、parcel_ownership宅基地确权。新增图层成本=注册entity_type+属性白名单,与既定架构一致。
2. **属性白名单直接来源**:三调DLTB 30字段(§2.2)、广东四图层字段(§6.1)、17图层M/C约束(§6.2)、设施台账11字段(§5.4-5)。
3. **关系三元组落点**:within_zone(parcel↔控制面,≥95%)、intersects(带OverlapNode,服务于"允许建设区内不能有基本农田图斑"等8条衔接约束的自动校验)、touches(相邻图斑)。
4. **EXECUTE通道消费函数**:指标核算(耕地保有量/基本农田/村庄建设用地规模 vs 下达指标)、管制规则校验(8条硬约束+留白≤5%/≤20%双口径)、结构调整表生成(三级地类×基期/目标)、图斑转换(一一对应+一对多四法)。
5. **数据获取优先级**:①三调/变更调查矢量(法定底数,不可替代)→ ②三区三线划定成果 → ③地籍/宅基地确权 → ④1:2000地形图/DOM → ⑤DEM/Landsat等公开数据补充 → ⑥驻村调查(问卷≥20%户数+台账)补属性与需求数据。与 `docs/gis/01_DATA_ACQUISITION_PLAN.md` 对齐复核。
