 二、优化方案

 Phase 1: KG Builder 空间要素入库（核心基础）

 1.1 新增保护边界入库方法

 文件: backend/app/modules/kg/builder.py

 新增 add_protection_zones(gis_data) — 入库4种保护边界：

- FarmlandProtection → 永久基本农田红线
- EcologicalRedline → 生态保护红线
- HistoricalProtection → 历史文化保护
- VillageDevBoundary → 村庄建设边界

 每个边界创建为 ControlLine 实体（使用已有的ontology），包含：

- 几何类型、面积
- 管制规则来源
- 与地块的空间关系（within_zone/protects）

 1.2 新增控制线入库方法

 新增 add_control_lines(gis_data) — 入库管控线：

- HazardControlLine → 灾害风险防控线
- FloodControlLine → 洪涝风险控制线（预留DEM依赖）
- ConditionalConstructionZone → 有条件建设区

 1.3 新增规划要素入库方法

 新增 add_planning_elements(gis_data) — 入库规划要素：

- LandUseZone → 土地用途分区（TDYT）
- ConstructionCtrlZone → 建设用地管制区（JSYDGZQ）
- PlanningScope → 规划村范围

 1.4 新增自然地理要素入库方法右键

 新增 add_natural_features(gis_data) — 入库自然地理要素：

- WaterFeature → 水系（从landuse DLBM推断或独立图层）
- GeologicalHazardPoint → 地质灾害点
- ElevationPoint → 高程点（预留）

 1.5 新增地形数据预留接口

 文件: backend/app/modules/kg/builder.py

 新增 add_terrain(terrain_analysis: TerrainAnalysisResult) — 预留接口：

- 将坡度分级、坡向分类、建设适宜性写入KG
- 为地块添加 pln:slope_class、pln:aspect_class、pln:suitability 属性
- 当前无DEM数据时，方法为空操作（不报错，留日志）

 1.6 地块实体增强

 为 Parcel 实体添加缺失属性：

- pln:centroid_x、pln:centroid_y — 质心坐标（从GeoJSON计算）
- pln:planning_zone — 规划分区（从DLBM推导）
- pln:vne_code — VNE分类码

 Phase 3: PARSE 空间消费增强

 3.1 注入设施分布摘要到LLM prompt

 修改 spatial_context.py 的 context格式化函数，在LLM prompt中注入：

- 设施分布表（类型×村组×坐标）
- 村名锚点（精确坐标，替换VillageGroup_N）
- 关键空间关系摘要

 3.2 新增PARSE KG查询工具

 在 agent.py 中新增 query_facilities 工具：

- 由 query_village_kg 工具统一路由
- 支持按村名、设施类型、坐标范围查询

 3.3 空间关系注入

 在 explore_targets 节点的prompt中注入空间关系摘要：

- 村组之间的方向关系（东/西/南/北）
- 设施与村组的包含关系
- 道路连接关系

 Phase 4: 栅格数据预留接口

 4.1 KG Builder 预留

 在 builder.py 中新增 add_terrain() 方法：

- 接受 TerrainAnalysisResult 类型
- 当前无DEM数据时为空操作
- 为地块添加坡度/坡向/适宜性属性

 4.2 SpatialContext 预留

 在 compute_spatial_context() 中新增 _compute_terrain_profile() 步骤：

- 接受 gis_data.get("terrain_analysis") 输入
- 产出 TerrainProfile 摘要（坡度分级面积占比、建设适宜性）
- 当前无数据时返回空，不影响现有流程

 4.3 查询模板预留

 新增 get_terrain_profile、get_parcels_by_slope、get_parcels_by_aspect 模板：

- 标记为P2优先级
- 数据不可用时返回空结果（不报错）
