## 四、系统数据缺口分析（2026-07-21 补充）

> 基于 Exa 搜索湖北/贵州/福建/安徽/陕西/云南/山西等省规程，对照 OUTPUT_ARCHITECTURE.md 识别缺失数据

### 4.1 缺失数据总览

当前系统（OUTPUT_ARCHITECTURE.md §一）定义了 4 类输入，但规程要求的以下数据**未定义输入层**：

| 缺失数据 | 规程依据 | 规划影响 | 优先级 |
|---------|---------|---------|--------|
| **DEM/坡度/坡向** | 所有省规程要求地形图/DEM | 建设适宜性评价、建设边界划定 | **P0** |
| **遥感影像(DOM)** | 三调规范必备、福建/贵州要求 | 现状判读、房屋轮廓提取 | P1 |
| **地名地址** | 规划编制基础（驻村调研） | 空间锚定（解决 parse 锚定断裂） | **P0** |
| **人口经济社会** | 湖北附录H、安徽附录B | 人均指标、发展水平判断 | P1 |
| **土壤/耕地质量** | 三调规范、土规数据库 | 农用地适宜性评价 | P2 |
| **水文/洪涝** | 防灾减灾要求 | 禁建区/限制建设区划定 | P1 |
| **上位规划** | 传导约束要求 | 指标衔接、边界落实 | P2 |

### 4.2 DEM 数据详细分析

#### 4.2.1 规程要求

各省规程均要求地形数据作为工作底图：

- **湖北**：村域≥1:2000地形图或数字正射影像图，居民点1:500-1:1000
- **安徽**：村域≥1:10000，重点区域≥1:1000
- **陕西**：村域1:5000-1:10000或≥0.5m影像图，建设区1:500-1:1000
- **福建**：建设边界内1:500-1:2000，村域1:2000-1:5000
- **云南**：集聚提升类1:2000，搬迁撤并类1:5000

#### 4.2.2 DEM 在规划中的关键作用

| 分析操作 | 输入 | 输出 | 规划决策影响 |
|---------|------|------|-------------|
| 坡度分级 | DEM | 0-6°/6-15°/15-25°/>25° 四级 | >25°禁止建设，6-15°限制建设 |
| 坡向分析 | DEM | 东/南/西/北等8方向 | 南坡优先居住，北坡避让 |
| 建设适宜性评价 | DEM+土壤+水文 | 适宜/较适宜/一般/不适宜 | 决定建设边界划定 |
| 洪涝风险分析 | DEM+水系 | 淹没范围(10/20/50年一遇) | 禁止建设区划定 |
| 道路选线 | DEM+坡度 | 最优路径(成本最小) | 规划道路走向 |
| 景观视域分析 | DEM+观景点 | 可视域/遮蔽域 | 景观资源保护范围 |

#### 4.2.3 数据获取途径

| 数据源 | 精度 | 覆盖 | 获取方式 | 成本 |
|--------|------|------|---------|------|
| SRTM 1-arc-sec | ~30m | 全球 | USGS EarthExplorer | 免费 |
| ASTER GDEM V3 | ~30m | 全球 | NASA Earthdata | 免费 |
| ALOS World 3D | ~12.5m | 全球 | JAXA | 免费(科研) |
| 天地图DEM | 30m/10m | 中国 | 天地图API | 免费(配额) |
| 地方1:10000 DEM | 5m | 省内 | 省测绘院 | 需申请 |
| 无人机航测 | 0.5-2m | 村级 | 自主航飞 | 设备+人力 |

#### 4.2.4 集成方案

**建议新增输入层**（在 OUTPUT_ARCHITECTURE.md §一 中补充）：

```
data/gis/jintian/terrain/
├── dem.tif           # 数字高程模型 (GeoTIFF, 30m)
├── slope.tif         # 坡度分级 (从DEM派生, 度)
├── aspect.tif        # 坡向分级 (从DEM派生, 度)
└── dom.tif           # 数字正射影像 (GeoTIFF, 0.5m)
```

**建议新增分析模块**：`app/modules/gis/analysis/terrain.py`

```python
class TerrainAnalyzer:
    def compute_slope(self, dem_path) -> str:       # DEM → 坡度栅格
    def compute_aspect(self, dem_path) -> str:      # DEM → 坡向栅格
    def classify_slope(self, slope_path) -> str:    # 坡度 → 四级分类
    def construction_suitability(self, ...) -> str: # 综合建设适宜性评价
```

**与 pipeline 的集成点**：

```
fetch_gis_data → [新增] fetch_terrain_data → build_kg → ...
                      ↓
                  TerrainAnalyzer.compute_slope()
                  TerrainAnalyzer.construction_suitability()
                      ↓
                  KG: parcel.pln:slope_class / parcel.pln:construction_suitability
                      ↓
                  MIP allocator: >25°坡度地块 → 禁止建设区硬约束
```

### 4.3 地名地址数据

**规程要求**：驻村调研需标注自然村名称与位置，三调数据库含地名地址数据。

**系统缺口**：parse 输出的操作引用自然语言地名（园寨/社前/田坑），但无法映射到 GIS 坐标。详见 `RELIABILITY_ASSESSMENT.md` §三（鸿沟1：空间锚定断裂）。

**建议新增输入层**：

```
data/gis/jintian/socio/
├── place_names.csv   # 自然村地名 (名称, 经度, 纬度, 所属VillageGroup)
├── poi.geojson       # POI兴趣点 (高德/天地图API获取)
├── population.csv    # 人口统计 (户数, 常住人口, 劳动力)
└── industry.csv      # 产业结构 (一产/二产/三产比例)
```

**数据源**：
- **villages-ML**（GitHub: jengzang/villages-ML）— 广东285,000+自然村坐标+语义标注
- **天地图地理编码API** — 村庄级地名→坐标查询
- **高德/天地图 POI API** — 设施点位获取

### 4.4 高程基准缺失

各省规程统一要求 **1985国家高程基准**，当前系统仅实现了平面坐标系（CGCS2000），缺少高程维度：

| 参数 | 规程要求 | 系统实现 |
|------|---------|---------|
| 平面坐标系 | CGCS2000 | ✅ EPSG:4490+zone |
| 高程基准 | 1985国家高程基准 | ❌ 无高程数据 |
| 投影方式 | 高斯-克吕格3°分带 | ✅ get_metric_crs() |
