## 1. 权威工作流程

### 1.1 广东省级流程（四阶段）

广东省技术指南 §二规定村庄规划编制四阶段：

| 阶段 | 人类规划师工作 | 系统对应 | 覆盖 |
|------|---------------|---------|------|
| **现状调查** | 资料收集 + 外业调查，形成规划工作底图 | ANALYZE 摄入 | ✅ 矢量/⚠️ 栅格 |
| **规划编制** | 科学规划 + 合理布局 + 村民协商，形成规划成果 | PLAN 闭环 | ❌ 单向 |
| **规划报批** | 乡镇政府编制，报上级审批，村内公示 30 日，村民会议同意 | 行政流程 | ❌ 不覆盖 |
| **规划公告** | 村委会保存 + 公告，作为村规民约执行 | 行政流程 | ❌ 不覆盖 |

### 1.2 国家级流程（六步骤）

《村土地利用规划编制技术导则》规定更细化的六步流程：

```
工作准备 -> 现状分析 -> 编制方案 -> 规划论证 -> 规划报批 -> 规划公告
```

**审批门槛**：经村民会议**三分之二以上**成员或者**三分之二以上**村民代表同意后，按程序报批。

> **系统启示**：2/3 超级多数同意门槛意味着规划方案需村民高度共识，系统应在 PLAN 阶段
> 输出"村民可理解版本"（直观易懂、好操作、能监督）。

### 1.3 现状调查的工作底图要求

- **坐标系**：2000 国家大地坐标系（CGCS2000）
- **比例尺**：一般 1:2000，可 1:1000 或 1:500
- **底图数据**：第三次全国国土调查数据成果（或最新土地变更调查）+ 数字线划图（DLG）+
  比例尺不低于 1:2000 的地形图或国土数字正射影像图（DOM）
- **补充数据**：农村地籍调查数据、地理国情普查及监测数据

> **系统启示**：工作底图 = 矢量（三调/地籍）+ 栅格（DOM/DEM/DLG）。系统当前只摄入矢量，
> 栅格（DEM/DOM）全部缺失。栅格是地形分析、建设适宜性的输入，不可跳过。

### 1.4 规划编制的协同性

规划编制不是规划师独断，需"组织村民充分发表意见，协商确定规划主要内容"。对应系统的
**人机协同底线**：不确定性由人消除，Agent 不做规划决策。

| # | 规划内容 | 核心要求 | 系统对应 |
|---|---------|---------|---------|
| 1 | 村庄发展目标 | 落实耕地保有量/基本农田/建设用地规模等约束性指标 | 指标表（附表 1） |

## 3. 规划成果

### 3.1 广东省级："一图一表一规则"

广东省技术指南 §四规定**基本成果**为"一图一表一规则"：

**一图** - 村庄规划总图（附录 1）：
- 比例尺不低于 1:2000，底图为 DOM 或地形图
- 五条核心控制线：生态保护红线、永久基本农田保护红线、永久基本农田储备区、
  乡村历史文化保护线、宅基地建设范围线
- 留白管控区：有条件建设区（≤现状建设用地 20%）
- 用地布局按附录 5 用地分类表分色填充
- 附表 1（规划目标表）+ 附表 2（土地利用结构调整表）直接附在图幅上
- 图框要素：指北针、比例尺、CGCS2000 公里网格线、图例、图名、制图单位/日期

**一表** - 近期建设项目表（附录 2）：11 列结构，8 大类项目：

| 列 | 字段 |
|----|------|
| 1-2 | 序号、项目类型 |
| 3 | 项目名称 |
| 4 | 空间位置 |
| 5-6 | 用地面积、建筑面积 |
| 7-8 | 资金规模、筹措方式 |
| 9-10 | 责任主体、协作部门 |
| 11 | 建设方式、备注 |

8 大类：生态修复整治 / 农田整治 / 垦造水田 / 拆旧复垦 / 历史文化保护 / 产业发展 /
基础设施和公共服务设施建设 / 人居环境整治。

**一规则** - 村庄规划管制规则（附录 3）：6 大类，以村规民约方式表述：

1. **生态保护**：红线范围 + 禁止建设活动 + 生态用地名录
2. **耕地和永久基本农田保护**：基本农田面积 + 集中分布区 + 占用审批程序 + 设施农用地管理
3. **历史文化传承与保护**：文保单位名录 + 历史文化保护线 + 修缮审批
4. **建设空间管制**：
   - 产业发展空间：经营性建设用地建筑密度/高度/容积率/绿地率
   - 农村住房：宅基地面积上限/建筑层数/高度/风貌
   - 基础设施和公服设施：退线距离/设施用地保护
5. **村庄安全和防灾减灾**：避开灾害区/消防通道/应急庇护场所
6. **其他管制规则**

**案例中的实际量化值**（冯园村村庄规划 §8）：
- 建筑高度：新建和改建建筑不宜超过 3 层，屋顶总高控制在 **10 米**以下
- 道路宽度：主干道 5-7 米 / 支路 3-5 米 / 巷道 2-3 米
- 垃圾收集点：50-60 户一个，服务半径 100-150m

### 3.2 国家级："两图两表一规则"

《村土地利用规划编制技术导则》规定成果为"两图两表一规则"：

| 成果 | 国家级 | 广东省级 |
|------|--------|---------|
| 图 1 | 土地利用**现状**图 | （底图，不单独交付） |
| 图 2 | 土地利用**规划**图 | 村庄规划总图（一图） |
| 表 1 | 土地利用规划**目标**表（附表 1） | 附表 1（附在图上） |
| 表 2 | **土地利用结构调整表**（附表 2） | 附表 2（附在图上） |
| 规则 | 土地利用规划管制规则 | 村庄规划管制规则（一规则） |

> **系统启示**：土地利用结构调整表（用地平衡表）是国家级必选成果，当前系统完全缺失。
> 该表结构为 3 大类（农业/建设/生态）× 4 列（现状面积/比重 + 规划面积/比重 + 增减），
> 需 L1 vs L4 逐地块对比汇总（见 `03_GAP_ANALYSIS.md` 断裂点⑤）。

### 3.3 土地利用结构调整表（附表 2）详细结构

| 大类 | 子类 | 说明 |
|------|------|------|
| **农业用地** | 耕地/园地/林地(商品林)/草地/其他农用地/合计 | 6 项 |
| **建设用地** | 城镇用地 + 农村居民点(宅基地/公服/经营性/基础设施/景观绿化/村内交通) + 采矿 + 对外交通 + 水利 + 风景名胜特殊(旅游/特殊) | 13 项 |
| **生态用地** | 水域/自然保留地/林地(生态林) | 3 项 |

列结构：`地类 | 现状面积 | 现状比重 | 规划面积 | 规划比重 | 规划期内增减`

> **关键规则**：林地按功能拆分--商品林归农业用地，生态林归生态用地。同一地类因功能
> 不同归入不同大类，系统需在分类时区分。

```

│   └── 村庄规划数据库.mdb          ← Personal Geodatabase, ArcGIS 9.3+

    ├── 村庄规划备案函.pdf
    └── 光盘成果目录清单.pdf
```

必选项：村庄规划总图.jpg、近期建设项目表.pdf、村庄规划数据库.mdb、村庄规划管制规则.pdf。
可选项：规划文本.pdf 及其他规划图件.jpg。

### 4.2 空间数据库规范

- **格式**：Personal Geodatabase（.mdb），ArcGIS 9.3 以上
- **坐标系**：CGCS2000，1985 国家高程基准，三度分带高斯投影
- **容差/分辨率**：Tolerance 0.001，Resolution 0.0001
- **4 必选图层**：GHCFW（规划村范围）、QMDLTB（期末地类图斑）、TDYT（土地用途分区）、
  JSYDGZQ（建设用地管制区）

### 4.3 数据质量 8 条硬约束

| # | 约束 | 系统对应 |
|---|------|---------|
| 1 | 不得调整永久基本农田 | MIP 硬约束锁定 |
| 2 | 不得调整禁止建设区范围 | MIP 硬约束锁定 |
| 3 | 建设用地规模不得增加 | 指标校验 |
| 4 | 建设用地规划为非建设用地规模不能增加 | 指标校验 |
| 5 | 永久基本农田图斑范围内土地规划用途必须为农用地 | conflict/detector |
| 6 | 允许建设区和有条件建设区范围内不能有永久基本农田图斑 | conflict/detector |
| 7 | 有条件建设区内不能规划有建设用地 | layout_validator |
| 8 | 限制建设区内不能有新增的规划城乡建设用地 | layout_validator |

> **系统启示**：当前系统已覆盖附件 2 检查编码，但 .mdb 输出、5 目录汇交结构、

## 5. 专业分析方法体系（教材）

### 5.1 调查方法

- **现场调查法**：实地踏勘
- **资料搜集**：上位规划、三调、地籍、地理国情
- **数据描述分析**：现状数据的统计描述

### 5.2 自然环境分析（栅格分析基础）

| 分析 | 内容 | 系统工具（待建） |
|------|------|-----------------|
| 地形条件分析 | 高程/坡度/坡向/起伏度 | `gis_analyze/terrain.py` |
| 城市用地适用性评价 | 自然条件综合适宜性分级 | `gis_analyze/suitability.py` |
| 环境容量分析 | 水/大气/噪声容量 | （远期） |

### 5.3 双评价（三区三线划定依据）

> **v2.0 修正**：教材明确"村庄规划中的双评价**一般落实上位国土空间双评价成果即可**"，
> 对具有特殊地理区位或重要生态功能的村庄才单独做单因子评价。优先级从 P0 降为 P1。

- **生态保护重要性评价**：生态系统服务功能重要性 + 生态敏感性
- **农业生产适宜性评价**：土地资源 + 水资源 + 气候 + 环境 + 灾害
- **城镇建设适宜性评价**：高程 + 坡度 + 坡向 + 地质灾害 + 交通可达性 + 基本农田

双评价成果空间落位 -> 三区三线衔接。系统通常只需落实上位成果，不重算。

### 5.4 用地分类使用规则

《国土空间调查、规划、用途管制用地用海分类指南》规定分类层级使用规则：

| 规划层级 | 使用层级 | 说明 |
|---------|---------|------|
| 全国国土调查 | 一级+二级为基础，三级为专项补充 | 24 一级类 / 113 二级类 / 140 三级类 |
| 国土空间总体规划 | **以一级类为主**，可细分至二级类 | 粗粒度 |
| 国土空间详细规划 | **使用二级类和三级类** | 细粒度--村庄规划属此层级 |

**分类规则**：不重不漏；多用途时以**主要功能**归类；鼓励混合利用 + 地上地下空间复合利用。

> **系统启示**：村庄规划属详细规划层级，应使用二级类+三级类。当前系统的 DLBM（三调编码）
> 是二级类，规划用途 GHYTBM 也应细化到二级或三级。

### 5.6 空间定位与地名解析（空间锚定方法论）

> **用途**：支撑系统从自然语言地名（"刘村小组东侧、晒谷场北边"）解析到具体 GIS 图斑
> 的完整方法论。这是 `create` 操作（原子操作中的项目落地）的前置依赖。
> **外部验证**：EACL 2026 "Coordinates from Context" 论文验证了 LLM 空间推理 + 传统
> Gazetteer 混合方法的有效性。

### 5.6.1 人类规划师如何定位

1. **现场踏勘**：驻村调研，在实地标注"园寨"、"社前"等自然村的位置和范围
2. **ArcGIS/QGIS 手工标注**：在规划工作底图上，根据调研结果手工绘制规划地块，
   用 DLMC（地类名称）字段聚类查找同名地块
3. **地名 -> 图斑匹配**：通过 DLMC 字段模糊匹配当前地类图斑的名称，
   结合 DLBM 编码筛选候选地块
4. **空间关系推理**：若文本描述"晒谷场北边"，规划师在底图上找到晒谷场图斑，
   向北偏移分析其北侧相邻地块

### 5.6.2 地名分类与语义标注体系

| 类别 | 示例 | 空间定位策略 |
|------|------|-------------|
| 聚落 | 园寨、社前、田坑 | 直接匹配自然村锚点 |
| 方位 | 东侧、北边、西南 | 从参照物向指定方向偏移 |
| 山地 | 分水坳、清明坳 | 匹配 DEM 地形特征 |
| 水系 | 沿河、溪边 | 匹配水系矢量图层，缓冲分析 |
| 农业 | 晒谷场、秧地 | 匹配 DLMC + DLBM |
| 植被 | 林地、竹林 | 匹配 DLBM 编码 |
| 基建 | 村口、桥头 | 匹配道路/桥梁/设施 POI |
| 姓氏 | 刘村、李屋 | 自然村名关联 |
| 象征 | 古树、庙前 | 匹配注记点 |

### 5.6.3 组合性位置描述解析策略

对"刘村小组东侧、晒谷场北边空地"这类复合描述，采用**分层解析**：

```
Step 1: 主锚点定位
  "刘村小组" -> Gazetteer 查询 -> VillageGroup_3 (中心坐标)
  -> 候选地块: [parcel_082, ..., parcel_105] (23个)

Step 2: 副锚点定位
  "晒谷场" -> DLMC 模糊匹配 -> 语义展开: DLBM 1510 (设施农用地)
  -> 在 VillageGroup_3 范围内筛选 -> parcel_089

Step 3: 空间关系推理
  "东侧" -> 从主锚点中心向东偏移 200m 搜索
  "北边" -> 从副锚点向北偏移，分析相邻地块
  -> parcel_088 (空闲地, 800㎡)

Step 4: 候选排序
  parcel_088: 空闲地, 800㎡, 在建设边界内, 不占基本农田 ✅
  -> 置信度: 0.85 (双锚点交叉验证)
```

## 6. 规划体系上下位关系

村庄规划处于国土空间规划体系的末端：

```
省级国土空间规划
  └─ 市级国土空间总体规划
      └─ 县级国土空间总体规划（如平远县）
          └─ 乡镇级国土空间总体规划（如泗水镇）
              └─ 村庄规划（"多规合一"实用性规划）
```

- **上位传导**：耕地保有量、基本农田保护面积、建设用地规模等约束性指标由上位规划下达
- **数据衔接**：村庄规划数据库须与镇级土地利用总体规划数据库衔接
- **"多规合一"**：村庄规划整合土地利用、建设、产业、生态等

> **系统启示**：`SpatialPlanningIntent` 的指标字段需区分"上位传导"vs"本级确定"。
> 上位规划文档已在 RAG 库（`05_上位规划/`），可作为约束来源。

## 7. 三种规划编制模式（2024-2025 政策转向）

> **来源**：自然资发〔2024〕1 号（千万工程通知）+ 自然资办发〔2025〕13 号（通则式通知）
>
> 这是 2024-2025 年最重要的政策转向，系统必须支持三种模式。

### 7.1 政策核心

千万工程通知明确指出：

> "不下达完成指标和完成时限，不盲目追求村庄规划编制'全覆盖'，不要求编制工作进度
> '齐步走'和成果深度'一刀切'。对没有需求、不具备条件的村庄可暂不编制规划。"

### 7.2 三种模式

| 模式 | 适用村庄 | 成果形式 | 编制主体 |
|------|---------|---------|---------|
| **完整编制** | 重点发展村庄 | 一图一表一规则（广东）/ 两图两表一规则（国家） | 单独编制 / 多村合并 / 与乡镇联合 |
| **通则式管理** | 无需单独编制的村庄 | **一图一表**（底线管控图+管控要求表）+ 附加图层 | 县级自然资源主管部门 |
| **不编制** | 无需求、不具备条件的村庄 | 纳入城镇控规或暂不编制 | - |

### 7.3 通则式管理规定（2025.4.10）

通则式管理的 4 项内容：

1. **底线管控**：耕地+永久基本农田+生态保护红线+历史文化保护红线+灾害风险防控线+
   重大项目建设控制范围 + **负面清单**（含农村乱占耕地建房"八不准"）
2. **规划管理要求**：村庄建设边界 + 各类用地选址范围/建设要求 + 村庄环境整体管控
3. **留白机动指标**：制定指标使用**正面清单**，供有特殊选址要求的设施使用
4. **工作衔接**：成果以**单独附加图层**形式纳入国土空间规划数据库

> **系统启示**：系统当前假设每个村庄都做完整编制。实际上很多村庄只需通则式管理。
> 系统输出架构需支持第三种模式--生成"一图一表"+附加图层，而非完整的"一图一表一规则"。

### 7.4 留白机动指标

千万工程通知规定：

> "预留部分规模作为规划'留白'机动指标"。
> "对空间区位有特殊要求、确需在村庄建设边界外选址的零星文化旅游设施、农业设施、
> 邻避设施项目等，在符合耕地保护等政策要求的基础上，可使用规划'留白'机动指标予以保障。"

### 7.5 建设用地规模硬上限

> "县域村庄建设边界规模不超过**2020 年度国土变更调查村庄用地(203)规模**"

这是比"建设用地规模不得增加"更精确的约束公式，系统应据此校验。

## 8. 基数转换：现状 -> 规划的映射方法

> **来源**：《实用性村庄规划编制手册》实验二
>
> 这是规划师将"三调"数据转换为规划基数的核心操作，是所有后续空间操作的前置步骤。

### 8.1 为什么要基数转换

三调数据采用"三调工作分类"（13 个一级类，68 个二级类），国土空间规划采用"国土空间规划
用途分类"（24 个一级类，113 个二级类，140 个三级类），两者存在编码差异，必须转换。

### 8.2 两种转换类型

**"一一对应"**（40+ 直接映射）：

| 三调编码 | 三调名称 | 规划编码 | 规划名称 |
|---------|---------|---------|---------|
| 0101 | 水田 | 0101 | 水田 |
| 0702 | 农村宅基地 | 0703 | 农村宅基地 |
| 0601 | 工业用地 | 1001 | 工业用地 |
| 0603 | 盐田 | 1003 | 盐田 |
| 1201 | 空闲地 | 2301 | 空闲地 |
| ... | ... | ... | ... |

**"一对多"**（需细分判别）：

| 三调编码 | 三调名称 | 规划子类 | 判别方法 |
|---------|---------|---------|---------|
| 05H1 | 商业服务业 | 0801-0807 (7 类) | POI 辅助 |
| 08H2 | 科教文卫 | 0802-0808 (7 类) | 地形图辅助 |
| 0809 | 公用设施 | 1301-1311 (11 类) | 影像判读 |
| 1004 | 城镇村道路 | 1207 城镇道路 + 0601 乡村道路 | 补充调查 |

### 8.3 GIS 操作流程（实验二）

```
Step 1: 导入三调【DLTB】数据 -> 按属性选择 ZLDWMC='XXX村' -> 导出数据

Step 2: 新建字段
  - JQXZYDFLDM（基期现状用地分类代码，文本，10 位）
  - JQXZYDFLMC（基期现状用地分类名称，文本，20 位）

Step 3: 字段计算器赋值
  - 按属性选择: DLMC = '水浇地'
  - 字段计算器: JQXZYDFLDM = "0102", JQXZYDFLMC = "水浇地"
  - 重复至所有"一一对应"地类转换完成

Step 4: "一对多"地类细分
  - POI/地形图/影像/调研辅助判别
  - 对每个子类分别筛选+赋值
```

> **系统启示**：基数转换是系统 ANALYZE 阶段必须执行的操作。当前系统的 ingest 层
> 做了 6 编码系统的验证，但没有做"三调->规划用途"的基数转换。这是"现状->规划"
> 映射的第一步，缺失则后续所有规划操作建立在错误的分类基础上。

## 9. 建设用地指标测算

> **来源**：《实用性村庄规划编制手册》§4.1.3
>
> 建设用地指标测算是村庄规划的核心经济逻辑--确定可用建设空间有多大、从哪来、怎么用。

### 9.1 建设用地分类关系（精确代码定义）

```
建设用地 = 城乡建设用地 + 区域基础设施用地 + 其他建设用地
城乡建设用地 = 城镇建设用地 + 村庄建设用地
村庄建设用地 = 07居住 + 08公服 + 09商服 + 1001工业 + 11仓储 + 0601乡村道路
            + 1208交通场站 + 1209其他交通 + 1301-1310&1313公用设施
            + 14绿地 + 16留白 + 2301空闲地 + 村庄范围(203)内其他用地
```

> **系统启示**：这是 `建设用地指标` 计算的精确代码级定义。系统当前没有这个定义，
> 无法自动计算"村庄建设用地规模"指标。

### 9.2 建设用地指标 6 大来源

| # | 来源 | 操作 |
|---|------|------|
| 1 | 核实三调数据 | 扣除宅前屋后非建设用地 |
| 2 | 宅基地面积超标 | 按现行标准扣除多余 |
| 3 | 一户两宅/多宅 | 腾退多余 |
| 4 | 散户/整体搬迁 | 重新安置 + 腾退 |
| 5 | 废弃宅基地/废弃建设用地 | 腾退 |
| 6 | 建设用地功能置换 | 无需多余指标 |

### 9.3 建设用地指标 4 大用途

1. 村庄居住用地（集中式/组团式）
2. 村庄公共服务用地
3. 村庄集体经营性用地
4. 其他建设用地

### 9.4 指标计算表

**表 4-2 村庄建设用地指标计算表**（9 列）：

| 村庄名称 | 基期建设用地 | 规划居住用地 | 规划集体经营性 | 规划公服 | 规划其他 | 留白用地 | 规划总建设用地 | 建设指标增减 |
|---------|------------|------------|-------------|---------|---------|---------|-------------|------------|

公式：`规划后建设用地 = 居住 + 集体经营性 + 公服 + 其他 + 留白 + 保持现状`

> **留白上限**：留白用地 ≤ 规划后总建设用地 × **5%**

**表 4-3 村庄宅基地面积计算表**（9 列）：

| 村庄名称 | 总户数 | 基期宅基地面积 | 基期户均宅基地 | 规划宅基地面积 | 规划户均宅基地 | 散户数量 | 安置区面积 | 预计安置户数 |
|---------|-------|-------------|-------------|-------------|-------------|---------|---------|-----------|

### 9.5 留白用地 3 种布局形式

1. **完整落图**：直接布局到建设空间
2. **不落图**：仅留指标作机动
3. **部分落图**：部分落位 + 部分机动

## 10. 三区划定规则（精确地类纳入清单）

> **来源**：《实用性村庄规划编制手册》§4.2-4.4
>
> 三区（生态/农业/建设空间）的划定不是凭空画线，而是基于精确的地类纳入清单。

### 10.1 生态空间

**纳入清单**：湿地 + 水域 + 裸地 + 其他草地 + 林业部门认定林地（生态林/防护林/生产林/风景林）
+ 双评价生态保护重要区 + 生态保护红线

**二级划分**：
- 生态红线保护区（落实上位生态保护红线）
- 一般生态空间（生态控制区）

### 10.2 农业空间

**纳入清单**：耕地 + 园地 + 林地 + 牧草地 + 其他农业用地（设施农用地/农村道路/田坎/坑塘水面/沟渠）
+ 商品林 + 双评价农业生产适宜区 + 永久基本农田储备区 + 高标准农田 + 整治项目区 + 耕地后备资源

**二级划分**：
- 永久基本农田保护区（落实上位划定成果）
- 一般农业空间（一般农业区/林业发展区/牧业发展区）

### 10.3 建设空间

**原则**："大分散，小集中"

**特别用途区**：农村道路/沟渠/裸土地/其他草地可划入建设边界但保持原用途

### 10.4 关键规则

- **林地按功能拆分**：商品林 -> 农业空间；生态林 -> 生态空间
- **三线不可调整**：生态红线/基本农田/城镇开发边界均为落实上位成果，村庄规划不可修改
- **全域土地综合整治可调整**：三区三线的调整须通过全域土地综合整治程序，非村庄规划权限

## 11. 实际空间操作：GIS 工作流

> **来源**：《实用性村庄规划编制手册》实验五（国土空间用地调整）
>
> 这是人类规划师在 ArcGIS 中实际操作地块的完整工作流。系统的"5 种原子操作"
>（create/split/merge/modify/reclassify）应对照此工作流设计。

### 11.1 操作本质

人类规划师的空间操作本质是**字段计算器驱动的属性重赋值**，而非几何重建：

```
核心操作：在"规划地类"字段中填写规划后的用地代码
  - 未调整地块：规划地类 = 基期现状地类（批量保持现状）
  - 调整地块：规划地类 = 新用地代码（逐个填写）
  - 部分调整：裁剪面工具裁剪 -> 分别填写
```

### 11.2 GIS 操作步骤

**步骤一：符号化设置**
- 加载基数转换后的数据
- 新建字段：基期现状地类 = [JQXZYDFLDM] & [JQXZYDFLMC]（代码+名称连接）
- 新建字段：规划地类、项目名称、用地调整类型
- 符号化：与国土空间用地用海分类符号库匹配

**步骤二：地类调整（用地结构调整）**

三种地块划分情况：

| 情况 | 描述 | 操作 |
|------|------|------|
| 情况一 | 调整地块 = 三调地块 | 直接在"规划地类"字段填写新代码 |
| 情况二 | 调整地块占三调地块一部分（**最常见**） | **裁剪面工具**裁剪 -> 分别填写 |
| 情况三 | 调整地块跨多个三调地块 | Shift 多选 -> 裁剪 -> 填写 |

**步骤三：批量保持现状**
- 排序"规划地类"字段
- 选择未调整的要素图斑（反选已调整的）
- 字段计算器：`规划地类 = [基期现状地类]`

**步骤四：计算面积**
- 字段计算器计算 TBMJ（图斑面积，椭球面积）

**步骤五：填写用地调整类型**

| 基期现状地类 | 规划地类 | 项目名称 | 用地调整类型 |
|------------|---------|---------|------------|
| 0201 果园 | 0703 农村宅基地 | 宅基地安置六组 | 农用地转建设用地 |

### 11.3 对系统原子操作的映射

| 人类操作 | 系统原子操作 | 说明 |
|---------|------------|------|
| 规划地类 = 基期现状地类（批量） | **reclassify**（保持现状） | 大多数地块不变 |
| 填写新用地代码 | **modify**（属性修改） | 改变 DLBM/GHYTBM |
| 裁剪面工具裁剪 | **split**（地块拆分） | 一个三调地块拆为多个规划地块 |
| Shift 多选合并填写 | **merge**（地块合并） | 多个三调地块合并为一个规划地块 |
| 新建图斑 | **create**（新建） | 少见--通常基于现有图斑操作 |

> **系统启示**：真实的规划操作是**属性重赋值为主、几何裁剪为辅**，不是从零画多边形。
> 系统的 EXECUTE Agent 应以 modify/reclassify 为主要操作，split/merge 在部分调整时使用，
> create 很少使用。当前系统以 MIP 分区分配 + procedural 生成为主，偏离了这一范式。

### 11.4 建设用地调整策略

教材明确的策略：

> "盘活存量、整体减量、局部增量"
> "搬迁零散居民点、拆除废旧宅基地、腾退废旧工矿用地"

操作顺序：
1. 先整体用地规划
2. 腾退废弃建设用地 -> 留出建设指标
3. 用腾退的指标新增建设用地
4. 部分村庄整理不出指标的，向乡镇/县申请新增和补划

## 12. 人口规模预测

> **来源**：《实用性村庄规划编制手册》§4.7

### 12.1 四种预测方法

**方法一：人口自然增长法**
```
P_t = P_0 × (1 + K)^t + (c - d)
```
P_0 = 基期人口, K = 自然增长率, t = 规划年限, c = 迁入人口, d = 迁出人口

**方法二：趋势外推法**
```
P_t = P_0 × (1 + r)^t
```
r = 综合增长率（含自然增长 + 机械增长）

**方法三：线性回归法**
```
Y = aX + b
```
基于历年人口数据回归

**方法四：劳动平衡法**
```
P = A / [1 - (B + C) / P_0]
```
A = 基本人口（劳动人口）, B = 服务人口, C = 被抚养人口

### 12.2 系统启示

人口规模是建设用地指标测算的输入（户均宅基地 = 宅基地面积 / 总户数）。系统应在 ANALYZE
阶段执行人口预测，将结果传入 PLAN 阶段的指标测算。

## 14. 规划实施全生命周期管理

> **来源**：千万工程通知 §六

### 14.1 全周期管理机制

```
编制 -> 审批 -> 实施 -> 监督 -> 体检评估 -> 修订
```

> "结合年度国土变更调查等开展规划实施**体检评估**，推动建立村庄规划编制、审批、实施、
> 监督的全周期管理工作机制。"

### 14.2 信息化支撑

- 依托国土空间基础信息平台
> 应用信息化手段提升村庄规划编制和实施的指导服务能力，有效控制规划编制和实施成本。
- 村庄规划成果纳入国土空间规划"一张图"
- 乡村建设规划许可证核发

### 14.3 责任规划师制度

> "建立健全乡村责任规划师制度"

将城乡规划编制单位和规划师下乡开展公益服务编制村庄规划，作为单位业绩考核和规划师
职称评定的加分项。

### 14.4 空间兼容与复合利用

> "探索村庄建设用地兼容和农业、生态空间复合利用"

优先保障农村一二三产业融合发展的空间需求。

### 14.5 历史文化名村特殊规则

> "历史文化名村、传统村落等特色保护类的村庄规划编制和实施应将各类遗产保护利用管理
> 要求统一纳入...防止搞成'两张皮'。"
