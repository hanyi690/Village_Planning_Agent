# 数据已迁移

本目录下的 GIS 数据已迁移至 `data/gis/jintian/`，按现状/规划/API 分类组织。

目录结构：
- `current/` — 现状数据（从工程文件 GDB 提取的村庄现状）
- `planned/` — 规划数据（规划设计中的目标状态）
- `api/` — API 获取数据（高德 POI、天地图 WFS）
- `project/` — 项目工程数据（非标准图层）
- `reference/` — 工程参考文件（DXF 转换脚本、SVG 渲染）
- `output/` — GIS 输出（E2E 截图、引擎结果）

详见 `data/gis/jintian/metadata.json`。
