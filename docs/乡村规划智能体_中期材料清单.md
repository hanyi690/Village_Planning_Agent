# 乡村规划智能体中期材料清单

> 提交对象：池泓文、甘顺豪
>
> 提交形式不限，两人共同整理一份能够反映实际情况的材料即可。已有文档、截图或成果证明可以直接提供。

## 一、项目研究进展情况

- [ ] **主要研究内容**：乡村规划智能体主要解决什么问题，当前包含哪些已经开展的研究模块。
- [ ] **拟解决的关键问题**：本子项目重点处理哪些规划业务或技术问题。
- [ ] **研究方案和研究过程**：采用了什么方法，已经经过哪些设计、开发、测试或案例应用过程。
- [ ] **当前实际完成情况**：哪些内容已经完成、哪些正在推进、哪些尚未开展。
- [ ] **阶段性研究结论**：目前能够从已有系统、实验或案例中得出什么结论。
- [ ] **与总课题的关系**：简要说明该子项目如何支撑县域产业智能规划与复杂决策研究。

## 二、研究进度、存在问题及解决方法

- [ ] 说明当前进度与原计划相比是否存在明显偏差。
- [ ] 列出实际遇到的主要问题，以及已经采取或准备采取的解决方法。

## 三、已取得的阶段性成果

请只提供实际已有的成果，没有则回复“无”：

- [ ] **论文**：论文题目、全部作者、发表时间、期刊/会议及期刊等级；尚未发表的说明当前状态，已有证明材料一并提供。
- [ ] **专利**：名称、全部作者、申请时间、申请号、授权时间、授权号和专利类型。
- [ ] **采纳批示**：报告题目、全部作者、采纳时间和采纳部门。
- [ ] **其他成果**：软件著作权、系统原型、规划报告、数据集、应用证明或其他能够列入中期成果的材料。

## 四、下一阶段工作计划及预期成果

- [ ] 下一阶段准备开展哪些工作。
- [ ] 预计形成哪些可检查的系统、实验、论文、报告或应用成果。

## 五、辅助撰写正文所需材料

前四部分已经说明的内容不必重复。以下材料不限定格式，可以直接提供已有论文内容、技术文档、图表、截图或文字说明：

- [ ] **任务图与调度机制**：说明规划任务如何拆分和建立依赖，多个专业维度如何并行或分阶段执行，多智能体如何协作。
- [ ] **知识与人机协同**：说明垂域知识如何进入规划流程，规划人员如何在关键环节审查、修改或继续执行，以及目前具备的空间信息输出能力。
- [ ] **代表性案例**：提供一个完整或基本完整的规划案例，包括主要输入、处理过程、人工审查、最终报告或空间输出和必要截图，用于支撑阶段性结论。
- [ ] **研究价值**：概括与硕士论文对应的研究问题或创新点，以及村庄规划方法如何支撑县域产业智能规划与复杂决策研究。
