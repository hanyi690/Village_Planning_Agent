## 六、实验设计与论文差异详细分析

### 6.1 法规引用幻觉率实验（论文4.3.1节）

| 对比项 | 论文描述 | 当前实现 | 差异评估 |
|--------|---------|---------|---------|
| **组别设计** | RAG开启/关闭两组对照 | G1/G2/G3三组设计 | ⚠️ **差异**：实现更精细 |
| **G1组** | RAG关闭 | L1关+L2关+L3关 | ✅ 对应论文"关闭组" |
| **G2组** | - | L1关+L2关+L3开 | ⚠️ 新增：仅L3获取知识 |
| **G3组** | RAG开启 | L1开+L2关+L3开 | ✅ 对应论文"开启组" |
| **幻觉率定义** | 未明确 | strict/lenient/weighted三种 | ✅ 增强：多定义支持 |
| **验证方法** | 人工核查 | KB索引验证+规则匹配 | ⚠️ 差异：自动化vs人工 |
| **知识携带污染** | 未提及 | 双固定上下文设计 | ✅ 增强：识别并解决 |

**关键差异说明**：

1. **组别扩展**：论文描述两组对照，实现扩展为三组，更精细分析RAG在不同层的效果
2. **验证方法差异**：论文描述"人工核查确认为虚构或错误"，当前实现为自动化规则匹配
3. **增强功能**：识别并解决了知识携带污染问题（双固定上下文设计）

**当前实现评估方法**：
```
Faithfulness评估：
1. 提取含数字、法规引用、标准编号的原子陈述
2. 在知识库上下文中验证支持度
3. 计算 supported_claims / total_claims

引用质量评估：
1. 正则匹配法规引用（法、条例、导则、条款）
2. 在KB中验证引用存在性
3. 计算引用准确性（关键词重叠度）
```

### 6.2 级联一致性检验实验（论文4.3.2节）

| 对比项 | 论文描述 | 当前实现 | 差异评估 |
|--------|---------|---------|---------|
| **场景数量** | 两个驳回场景 | scenario1 + scenario2 | ✅ 一致 |
| **场景1** | 驳回规划定位 | planning_positioning驳回 | ✅ 一致 |
| **场景2** | 驳回自然环境分析 | natural_environment驳回 | ✅ 一致 |
| **评估方法** | 未明确具体算法 | Embedding(70%) + 关键词(30%) | ⚠️ 差异：具体实现不同 |
| **影响树计算** | 未明确 | BFS遍历依赖DAG | ✅ 完整实现 |
| **波次调度** | 未明确 | 严格波次调度机制 | ✅ 完整实现 |
| **语义一致性** | 检索关键词语义要素 | Embedding语义相似度 | ⚠️ 差异：向量化vs关键词 |

**当前实现评估方法**：
```
目标维度评估（反馈响应度）：
score = positive_coverage * 0.5 + negative_removal * 0.3 + content_change * 0.2

下游维度评估（语义对齐度）：
score = embedding_similarity * 0.7 + keyword_coverage * 0.3

Embedding相似度：
- 使用 AliyunEmbeddings (text-embedding-v4)
- 余弦相似度归一化: normalized = max(0, (cosine_sim - 0.3) / 0.7)
```

**已知问题**（来自实验文档）：
- 修订未产生内容变化（分叉机制可能未正确触发）
- 部分Embedding调用失败
- 关键词映射覆盖率有限

### 10.2 新级联修复场景设计

基于上述实际差异，设计以下三个级联修复场景：

---

#### 场景一：驳回规划定位（Layer 2）- 修正村庄分类

**目标维度**：`planning_positioning`（规划定位）

**驳回反馈**：
```
金田村根据《平远县国土空间总体规划（2021—2035年）》被划定为"集聚提升类村庄"，
而非"特色保护类村庄"。请修正规划定位，调整为：
1. 村庄分类：集聚提升类
2. 发展定位：特色南药综合开发示范村
3. 产业方向：以南药种植、加工、销售为主导
```
