### 当前合理规划图层的判定

规划图层只允许来自同一 run 的：`L1/L3 source refs → TARGET_PROJECTION admitted target → GROUND candidate geometry/availability → ScenarioSet feasible/recommended → ApprovedExecutionInput → Atomic EXECUTE → ValidationCertificate → DELIVER`。其中：

- `fully_unavailable` 不进入正式候选；`partially_available` 必须带 eligible/excluded geometry 和面积；`fully_available` 也可以只分配一个 footprint，但必须保留同源 remainder；
- 相邻地块不是自动执行成员。必须同时有 typed adjacency/topology、邻地几何/evidence、明确 worker task 和同一 approved task set；
- 普通人口总数、注记、设施数量不会猜成 coverage demand；道路现状不会复制成规划道路；topology/coverage 没有完整输入时只交付诊断和现状参考层；
- 前端显示的是本次 committed planned state 和诊断定位，不把 current landuse、recall-only geometry 或 deferred target 伪装成规划结论。

因此，当前仍是“同源地块窄切片已真实闭合 + 全村规划 PARTIAL/GAP”：coverage demand、真实道路 route/cost、topology/layout、全村多类 worker 混合执行和新结构化代码后的 fresh provider 正向会话仍是下一阶段验收项。
