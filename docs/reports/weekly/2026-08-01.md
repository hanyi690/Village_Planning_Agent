### 5. 工程健壮性：进程自结束机制（8/1）

**问题**：aiosqlite ≥0.22 worker 线程非 daemon，阻塞 `queue.get()`，崩溃/完成后进程永不退出（实测两次挂死）。

**四层防御**：
1. `shutdown_database()`（engine.py）— checkpointer 裸连接（`get_global_checkpointer` 直连不经 engine，`AsyncSqliteSaver` 无 close API → 直接关 `conn`）+ engine 无条件 dispose（跳过引用计数陷阱）
2. `run_with_exit_guard`（CLI 统一入口）— daemon watchdog，主协程完成后 10s 未退出 → `os._exit` 强杀（任何漏网线程逃不掉）
3. 环节超时 — MIP `PULP_CBC_CMD(timeLimit=120/30, gapRel=0.05)`（已有）+ `pipeline.ainvoke` 外层 `asyncio.timeout(900)`
4. `run_state.json` 阶段断点（崩溃可续跑）

**实测**：崩溃路径（人为异常）与正常路径均正常退出（日志 `All database connections shutdown`）。
